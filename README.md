# test_menu_flutter

A manual test menu as a Flutter app, and unchanged `package:test` files run
as a menu on a device: see the package
[tekartik_test_menu_flutter](test_menu_flutter/README.md).

## Setup

pubspec.yaml:

```yaml
dependencies:
  tekartik_test_menu_flutter:
    git:
      url: https://github.com/tekartik/test_menu_flutter
      path: test_menu_flutter
    version: '>=1.3.0'
```

Examples: [test_menu_flutter_example](test_menu_flutter_example/lib/main.dart),
[example/min_app](example/min_app), [example/in_app](example/in_app).
